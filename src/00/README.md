# 00 — system

*[← the sample catalogue](../../SAMPLES.md)*

**This is not the learning path.** The samples to learn from live in
[`src/01`](../01) — read them in [SAMPLES.md](../../SAMPLES.md), or on
[the sample path](https://abap2ui5.github.io/samples/), the same catalogue
as a page.

`00` is the system package: the apps held back by maturity or purpose. They
are linted like everything else, but none of them gets a tile in the overview
app or a card on the sample path, and the `702` branch strips this package
whole — a system on NW 7.02 never sees it.

| Package | What it holds | Who it is for |
|---|---|---|
| [`00/97`](97) "experimental" | work in progress — samples not finished yet | authors still working on them |
| [`00/98`](98) "testing" | test and scaffolding apps, not demos | framework testing — these apps exist to be run by a check, not learned from |

Both packages are listed at the end of [SAMPLES.md](../../SAMPLES.md)
("Not in any overview"), reachable by class name only.
